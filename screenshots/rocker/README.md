# Rocker — desktop metronome

`metronome-desktop-v1.jpg` is an unmodified desktop browser screenshot of the public Rocker application at https://rocker-rust.vercel.app/metronome, captured on 2026-09-09 at a 1440 × 1000 viewport. The screenshot shows the Studio theme, 100 BPM, 4/4 and the pendulum view. The metronome is stopped. No microphone access, audio input or generated artwork was used.

Used as the desktop preview on the Rocker catalog card and in its screenshot gallery at https://jenda.cool/#app=rocker.
