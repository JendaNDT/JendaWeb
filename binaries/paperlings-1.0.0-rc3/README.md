# Paperlings 1.0.0-rc3 – Android

Otevři stažené APK a na výzvu povol instalaci. Pokud už máš rc2, nainstaluj rc3 přímo přes ni, bez odinstalování — uložený postup zůstane. Starší testovací aplikaci Lemmings 2026 tento balíček neaktualizuje.

Android 7.0+, ARM32/ARM64. Aktualizace vykreslování na telefonech a tabletech: HD viewport a sdílená geometrie trávy. Na displejích s vysokým rozlišením může být obraz mírně měkčí. 24 misí a čtyři hudební skladby zůstávají.

Windows používá nadále balíček 1.0.0-rc2 s hudbou.
